## 分支说明

- `Main`：初始 Android 工程（Android Studio 生成的 Hello World 模板）。
- `Dev`：实验六开发分支，在 Main 的基础上准备开发环境。
- `Frag`：在 Dev 分支上新建，完成实验六的全部功能：
  - 个人信息 Fragment
  - 两张牌翻牌游戏 Fragment
  - 三张牌翻牌游戏 Fragment
  - 使用 `ObjectOutputStream` / `ObjectInputStream` 和 `openFileOutput` / `openFileInput`
    对个人信息与游戏历史进行序列化存储

实验六的完整实现请切换到 `Frag` 分支查看。
